# Koz

Tema do repositório `eusouproton/vencord-theme`.

## Arquivos

| Arquivo | Função |
| --- | --- |
| `koz.theme.css` | Entrada principal do tema |
| `chillax-core-lite.css` | Base de transparência e superfícies |
| `blurple-recolor-lite.css` | Recolorização leve |

## Wallpaper

O tema usa `../rem.jpg` como wallpaper. O arquivo fica na raiz do repositório para evitar duplicação.

## Fluxo do tema

`koz.theme.css` → `chillax-core-lite.css` → `blurple-recolor-lite.css` + ajustes locais

O objetivo é manter o Chillax como base, mas controlar localmente os efeitos para que o wallpaper permaneça nítido e o blur fique restrito às superfícies que precisam dele.
